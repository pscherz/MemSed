How to search

1. Enter the value to find and choose its type.
2. Click First Search.
3. Change the value in the target process.
4. Use Next Search, Higher, or Lower to narrow results.
5. Add an address to the scratchpad, then press enter or click Apply to update the value.
6. Enable Locked to reapply it continuously if needed.
